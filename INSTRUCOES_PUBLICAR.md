# Como Publicar no GitHub

## Passo 1: Criar Repositório no GitHub

1. Acesse: https://github.com/new
2. Nome do repositório: `sistema-multi-agente-cidades-brasil`
3. Descrição: "Sistema Multi-Agente para consulta de dados econômicos e climáticos de cidades brasileiras"
4. Marque como **Public** (ou Private se preferir)
5. **NÃO** marque "Initialize with README"
6. Clique em "Create repository"

## Passo 2: Adicionar Remote e Fazer Push

Execute os comandos abaixo:

```bash
cd /home/mariana-assis/Documentos/Atividade_tec/sistema-multi-agente-cidades-brasil

git remote add origin https://github.com/usergh12/sistema-multi-agente-cidades-brasil.git

git push -u origin main
```

## Pronto!

Seu repositório estará disponível em:
https://github.com/usergh12/sistema-multi-agente-cidades-brasil
